Variable	Kahan se milega
GOOGLE_CLIENT_ID	Google Console
GOOGLE_CLIENT_SECRET	Google Console
ONLY_LOGIN_WITH_GOOGLE	Khud likhna hai: true ya false
NEXT_PUBLIC_VAPID_PUBLIC_KEY	Command se generate
VAPID_PRIVATE_KEY	Usi command se generate
VAPID_SUBJECT	Khud likhna hai: apna email
CRON_SECRET	Command se generate


2. ONLY_LOGIN_WITH_GOOGLE
Testing ke liye false rakhein, taaki Google setup mein gadbad hone par bhi aap password se login kar sako. Google login chal jaye, tab true karein.

3. VAPID keys
Project folder mein yeh chalayein:


npx web-push generate-vapid-keys
Output mein do keys aayengi:

Public Key ko NEXT_PUBLIC_VAPID_PUBLIC_KEY mein daalein.
Private Key ko VAPID_PRIVATE_KEY mein daalein.
Yeh command sirf ek baar chalani hai. Local aur production mein same keys rakhna sabse simple hai, ya production ke liye alag pair bana lein. Production ki keys baad mein badalne par users ko reminder dobara set karna padega.

4. VAPID_SUBJECT
Yeh koi secret nahi hai, bas contact address hai. Aage mailto: lagakar apna email likhein:


VAPID_SUBJECT=mailto:aapka-email@example.com
5. CRON_SECRET
Yeh aapka banaya hua password hai, kisi website se nahi milta:


node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
Output CRON_SECRET mein daalein. Scheduler (jaise cron-job.org) mein bhi yahi value is header mein jayegi:


Authorization: Bearer <CRON_SECRET>
Final .env.local
Yeh values .env.local mein daalein, .env.example mein nahi, kyunki .env.example git mein commit hoti hai. Yeh sab purani values ke neeche add karein:


GOOGLE_CLIENT_ID=xxxx.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=GOCSPX-xxxx
ONLY_LOGIN_WITH_GOOGLE=false

NEXT_PUBLIC_VAPID_PUBLIC_KEY=<public key>
VAPID_PRIVATE_KEY=<private key>
VAPID_SUBJECT=mailto:aapka-email@example.com
CRON_SECRET=<generated secret>

Earning


List app mein sirf ads se shuru mein zyada paisa nahi aata. Agar 1,000 daily users 5 page dekhein aur ₹20–80 per 1,000 views milein (yeh mera andaza hai), to ₹3,000–12,000/month banta hai. Itna to hosting ka kharcha hi ho sakta hai.

Main is order mein karunga:

Affiliate links: item ke paas "Buy" button (Amazon, BigBasket). Yeh sabse sasta aur sabse natural hai, kyunki log kharidne ki list hi bana rahe hain. Rates check kar lena, sources mein grocery 3–8% ke beech alag-alag mile.
Business plan (₹299+/month): kirana, event planners, societies ke liye team lists, export aur reports. Yahan ek customer kai aam users ke barabar kamata hai.
Pro plan (₹49–99/month): no ads, recurring reminders, budget reports. Razorpay lagbhag 2% + GST leta hai.
Ads: traffic aane ke baad.
Ads kaise lagayein
Pehle yeh zaroori hai:

Vercel Pro: Hobby plan par commercial use allowed nahi hai.
Public landing page: abhi logged-out visitor sidha /login par jata hai, to Google ko dekhne ke liye content nahi milega.
Public content: list templates aur articles ("monthly grocery list" jaise), jo search se traffic bhi layenge.
Policy pages: privacy policy, terms, contact, aur account delete ka option.
AdSense steps:

adsense.google.com par site add karo.
Unka script root layout mein lagao aur public/ads.txt daalo.
Approval ke baad pehle public pages par ad units lagao.
Ads kahan nahi lagane: login aur error pages, chat, aur guest share pages. Google non-content aur private communication wali screens par ads allow nahi karta, aur share pages par users ka unchecked content hota hai. Login ke peeche ads ke liye crawler login setup karna padta hai.

Payment: USD threshold $100 hai. INR ka figure sources mein alag-alag mila, to apne AdSense account mein dekh lena.

Dusre ad networks: Adsterra aur Monetag jaise networks mein approval aasan mana jata hai, par maine inhe verify nahi kiya. Inke popups se users bhagte hain, isliye main avoid karunga.

Play Store: agar app wahan daalo aur digital plan becho, to Google Play Billing lagana zaroori hai.

Aapse chahiye
Tests: kya main failing tests dhoondh kar theek karun, aur feedback test ki 2 lines update karke poora check chalaun? Aapne test ke liye mana kiya tha, isliye ruka hoon. Yeh commit se pehle zaroori hai, aur main yehi recommend karta hoon.
App kahan deployed hai? Scaling ki kuch salah (Redis, cron, IP limits) iske hisaab se badalti hai. Maine Vercel maan kar likha hai, par code mein iska koi pakka saboot nahi mila.
